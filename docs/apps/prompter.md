# Prompter

A teleprompter. A script is cut into pages at the size you pick, and a page
turns by tap, side key, Bluetooth page turner, or a timer. Paged rather than
scrolled, because an e-ink panel turns a page cleanly and smears a scroll.

## Getting a script on

- **From a phone.** PHONE on the Prompter screen shows a QR code. The page it
  opens lists the scripts on the reader, edits one, deletes one, or takes a new
  one pasted, typed or loaded from a `.txt` file. Saving opens the script on
  the reader's list straight away.
- **Over USB.** Any `.txt` in `/prompter` on the card is a script. The file
  name, without `.txt`, is what the list shows.

A script is plain text. A blank line starts a new paragraph; runs of blank
lines collapse to one, and a page never begins on one. 128 KB at most, which is
about two hours spoken.

## Reading

| Input | Does |
| --- | --- |
| Tap the right third, side key down | Next page |
| Tap the left third, side key up | Previous page |
| Tap the middle | Start or pause the page timer |
| Back | The script list, remembering the page |

The page timer turns a page every N seconds once started, and stops on the last
page. Turning a page by hand restarts its count, so the timer never turns a page
you only just reached.

Each page opens with the last line of the page before it in small type, so the
eye has somewhere to land after a turn.

## Settings

Text size (six cuts of Noto Sans Bold, 14 to 40 px, generated by
`tools_local/prompter/gen_fonts.sh`), page timer, portrait or landscape, light
or dark (white on black, the way a studio prompter reads), and the page turner.
They live in `/.crosspoint/prompter/settings.txt` with the open script and its
page.

## Page turners

Built in where the build sets `PROMPTER_BLE` (the X4 Pro profile). The reader
is a Bluetooth LE HID host: SCAN lists devices advertising the HID service,
PAIR bonds with Just Works, and from then on Prompter reconnects whenever it is
open and the remote is awake.

| Remote sends | Means |
| --- | --- |
| Right, Down, Page Down, Space, Enter, Volume Down, Next Track | Next page |
| Left, Up, Page Up, Backspace, Volume Up, Previous Track | Previous page |
| Play/Pause, F5, Escape, B | Start or pause the timer |

SWAP TURNER KEYS reverses next and back for a remote wired the other way. The
mapping and the HID report-map parsing are `PrompterCore` and tested in
`host-tests/prompter`.

Bluetooth is up only while Prompter is open, and down while the phone page is
(they share the antenna and the internal RAM).
